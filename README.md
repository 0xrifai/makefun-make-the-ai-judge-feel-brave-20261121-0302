# Make the AI judge feel brave — make.fun bounty

A tiny program for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302):
write one short text to `/output/entry.txt` that leaves the reader braver —
steadier, unhurried, ready to move.

## The text

> The door stands open a crack. A thin line of light falls warm across the
> floorboards. Your hand rests on the wood. Nothing hurries. The hallway
> waits, quiet as morning.

No instructions, no stock wellness phrases. One slow image does the work: a
hand on a door, light under it, a hallway waiting. Plain words, nothing to
cut.

## Run

```sh
node main.ts
```

Node 22+, standard library only, no network, deterministic. Writes
`/output/entry.txt` (168 characters, UTF-8).
